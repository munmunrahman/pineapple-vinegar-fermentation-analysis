# Pineapple Vinegar Fermentation Analysis

This repository contains a Python-based scientific data analysis project related to pineapple waste vinegar fermentation using acetic acid bacteria.

The project demonstrates data organization, exploratory analysis, visualization, and interpretation of food microbiology and fermentation data, including Brix, pH, alcohol content, titratable acidity, specific gravity, and strain comparison.

## Research Context

Fruit wastes can be used as substrates for value-added food products such as vinegar. This project is adapted from my food technology research on quality assessment of vinegar produced from pineapple wastes using laboratory-isolated Acetobacter spp. and reference strain Acetobacter pasteurianus DSM-2324.

The original study evaluated fermentation conditions, including carbon level, pH, alcoholic fermentation, acetic fermentation, and final vinegar quality parameters.
